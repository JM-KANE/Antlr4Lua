# Antlr4Lua

A Lua compiler/interpreter built with ANTLR4 and C++. This project aims to explore core compiler construction techniques by building a complete toolchain from frontend (parsing) to backend (virtual machine execution).

## Features & Design

- **Complete compilation pipeline** – implements both frontend and backend.
  - **Frontend**: Lexer/parser generated by ANTLR4 from a `.g4` grammar file.
  - **Backend**: Custom bytecode and virtual machine.
- **Native C++ implementation** – can be embedded as a static library or standalone runtime.
- **Modular architecture** – clear separation of concerns for learning and extension:
  - `parser/` – syntax analysis and error collection.
  - `code_gen/` – bytecode generation and optimizations.
  - `vm/` – instruction dispatch, runtime environment, and execution.
  - `antlr4/` – ANTLR4 C++ runtime (included as a submodule).

## Project Structure
```
Antlr4Lua/
├── parser/             # Syntax analysis (ANTLR4 grammar)
│   ├── LuaLexer.g4     # Lexical rules
│   ├── LuaParser.g4    # Grammar rules
│   └── *.cpp/h         # Custom lexer/parser logic
├── code_gen/           # Code generation
│   ├── CodeGen.cpp     # Bytecode emitter
│   └── FuncInfo.h/cpp  # Function infomation and prototype
├── vm/                 # Virtual machine
│   ├── State.h/cpp     # Runtime state (stack, environment, call frames)
│   ├── Instruction.cpp # Instruction decoding & dispatch
│   └── stdlib/         # Standard library implementations
├── antlr4/             # ANTLR4 C++ runtime (submodule)
├── main.cpp            # Program entry point
└── CMakeLists.txt      # Build configuration
```

## Getting Started: Build & Run

### 1. Prerequisites
- C++20 compatible compiler
- CMake (3.20+), ninja
- Java Runtime Environment (for ANTLR code generation)

### 2. Clone the Repository
The repository includes the ANTLR4 C++ runtime as a submodule. Clone with:
```bash
git clone https://github.com/JM-KANE/Antlr4Lua.git
cd Antlr4Lua
git submodule update --init --recursive
```

### 3. Configure ANTLR4 Code Generation
Download the ANTLR4 Java tool from [antlr.org](https://www.antlr.org/download/antlr-4.13.2-complete.jar) (or use a package manager). e.g in Linux:

```bash
cd /usr/local/lib
curl -O https://www.antlr.org/download/antlr-4.13.2-complete.jar
```
Then set CMake cache varible `ANTLR_PATH` to to the directory where the jar file is located. You can do this by adding a `CMakeUserPresets.json` file or by using the CMake command line when configuring/building.

### 4. Build
This project leverages `CMakePresets.json` to simplify configuration and build. You can list available configure and build presets:
```bash
cmake --list-presets
cmake --build --list-presets
```
Then you configure and build with a preset (e.g., `linux-release`)
```bash
# Configure using the 'linux-release' preset
cmake --preset linux-release

# Build using the same preset
cmake --build --preset linux-release
```
You can also use visual studio IDE or visual studio code to build cmake project on windows/linux, please refer to the following link:
* [CMake projects in Visual Studio](https://learn.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio)
* [Create a CMake hello world project with CMake Quick Start](https://code.visualstudio.com/docs/cpp/cmake-quickstart)

> 💡 Note
> If you want a debug build or other configuration, use the proper preset instead (or create your own `CMakeUserPresets.json`). The preset defines compiler and compiler flags, cache variables, build directory, and generator automatically.

### 5. Run Examples
After building, launch the REPL (interactive interpreter) with (e.g., `linux-release`):
```bash
./out/build/linux-release/luac
```

Or execute a Lua script:
```bash
./out/build/linux-release/luac *.lua [args for main(...)]
```
